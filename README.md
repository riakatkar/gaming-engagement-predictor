# 🎮 Gaming Engagement Predictor

A Streamlit web application that predicts a player's engagement category (**Low, Medium, or High**) using a tuned Decision Tree classifier.

## Project result

The accompanying `gaming.ipynb` notebook reports:

- Test accuracy: **90.23%**
- Macro F1-score: **89.77%**
- Best GridSearchCV parameters: `criterion='entropy'`, `max_depth=12`, `min_samples_leaf=10`, `min_samples_split=2`
- Final pruned pipeline: `ccp_alpha=0.000357`

The app displays metrics generated by `train_model.py` when you train locally. The notebook's reported score is shown only as a reference until then.

## Features

- Predict player engagement from player and gaming activity details.
- Display predicted class and class probabilities.
- Use the same preprocessing and Decision Tree pipeline as the notebook.
- Handle unseen categorical values through `OneHotEncoder(handle_unknown='ignore')`.

## 1. Clone the repository

```bash
git clone <your-github-repository-url>
cd gaming-engagement-predictor
```

## 2. Create and activate a virtual environment

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 3. Install dependencies

```bash
pip install -r requirements.txt
```

## 4. Add the dataset and train the model

Place your original dataset at:

```text
data/online_gaming_behavior_dataset.csv
```

Then run:

```bash
python train_model.py
```

This creates the model pipeline and evaluation metrics inside `models/`.

**Important:** The dataset is not included in this starter project because it was not attached with the notebook. Use the same source dataset that you used to produce the notebook's reported result. The script reproduces the final pipeline's preprocessing, split, and classifier settings; verify that the resulting metrics match your notebook before deployment.

## 5. Run the Streamlit app

```bash
streamlit run app.py
```

Streamlit will open the application in your browser.

## 6. Push to GitHub

```bash
git add .
git commit -m "Build gaming engagement prediction app with Streamlit"
git push origin main
```

The dataset and generated model are ignored by Git. Keep the dataset's licence and redistribution terms in mind. For deployment, you must make the trained model artifact available to the hosting environment (for example, through an approved private download/build process or a permitted tracked artifact).

## 7. Deploy on Streamlit Community Cloud

1. Push the source code to a GitHub repository.
2. Open [Streamlit Community Cloud](https://share.streamlit.io/).
3. Create a new app and select your repository, branch, and `app.py`.
4. Ensure the trained model artifact is available at `models/final_engagement_tree_pipeline.joblib` in the deployed environment.
5. Deploy the app.

## Input features

`Age`, `Gender`, `Location`, `GameGenre`, `PlayTimeHours`, `InGamePurchases`, `GameDifficulty`, `SessionsPerWeek`, `AvgSessionDurationMinutes`, `PlayerLevel`, and `AchievementsUnlocked`.

## Limitations

- Prediction quality depends on the training data and its label-generation process.
- The model's class probabilities are model estimates, not guarantees.
- The notebook's high feature importance for session frequency and session duration should be investigated for possible target leakage before making strong claims about real-world predictive performance
